# AI Business Insights Copilot

## Project Objective
Build an AI-powered business analytics platform that enables users to analyze sales data, visualize business KPIs, and ask questions in natural language using AI.

## Business Problem
Businesses collect large amounts of sales data but often struggle to derive quick, actionable insights. This project combines SQL, Python, Power BI, and AI to simplify business analysis.

- MySQL
- Python
- Pandas
- Power BI
- Streamlit
- Gemini API
